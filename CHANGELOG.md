# Changelog

## [1.0.3] - 2026-10-08

### Changed

- **Gameplay**: `GameObjectDestroyer` — optional `delay` (seconds) before each target is destroyed via `Destroy(target, delay)`.

## [1.0.2] - 2026-10-05

### Added

- **Gameplay**: `GameObjectDestroyer` — destroy a list of `GameObject` references via `DestroyTargets()` (Odin button, UnityEvent-friendly).

## [1.0.1] - 2026-10-05

### Added

- **Gameplay**: `GameObjectToggle` — enable/disable a list of `GameObject` references via `SetEnable()` / `SetDisable()` (Odin buttons, UnityEvent-friendly).
